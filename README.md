# Satla Vivek Kumar — Portfolio

Interactive portfolio website for **Satla Vivek Kumar** — Aspiring Business Analyst & Master's Candidate.

## 🚀 Overview

- **Design Language:** Dark atmosphere aesthetic inspired by modern design portfolios, featuring smooth scroll reveal animations, custom serif typography, dynamic dusk gradients, and noise grain texture.
- **Hero Section:** "Hello, I'm Vivek" with role taglines for Business Analysis, operations & finance optimization, and graduate studies aspirations.
- **About:** Details educational foundation (GITAM University, B.A. in Economics, History & Psychology, First Class with Distinction) and real-world hotel operations management experience.
- **Selected Works:** Hands-on operational case studies (hotel financial management, process optimization, applied economics).
- **Interactive Portrait Preview:** Hovering over or tapping the name at the footer triggers a floating cursor-following preview card with portrait photos.
- **Resume Integration:** Integrated single-page PDF download and preview.
- **Fully Responsive:** Custom mobile styles for phones, tablets, and desktop displays with safe-area notch support.

## 🛠️ Tech Stack

- HTML5 / CSS3 (Tailwind-compatible styling)
- Modern Vanilla JavaScript & ES Modules
- Draco 3D Decoders & Three.js support
- Inter & Swanky and Moo Moo typography

## 💻 Local Development

Serve the root directory with any local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Open `http://localhost:3000/` in your browser.
